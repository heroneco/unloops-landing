# Unloops landing

A single-page Astro landing site for Unloops, styled with Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

Build the static site with `npm run build`. The page lives in `src/pages/index.astro` and the shared document layout is in `src/layouts/Layout.astro`.

All calls to action open [the Unloops app](https://app.unloops.org/).
